# متصفح مصغر

يفتح أي رابط ويعيد تحميل الصفحة كاملة كل 1800 ثانية (30 دقيقة).

- `app/` تطبيق أندرويد: خدمة أمامية تحمّل الرابط في WebView وتعيد تحميله كل 1800 ثانية حتى مع إغلاق التطبيق — الرابط الافتراضي https://dreams.xo.je/
- `web/index.php` نسخة PHP (iframe) — تفشل مع المواقع التي تمنع الإطار

## بناء APK
تبويب **Actions** ← **Build APK** ← **Run workflow** ← بعد النجاح نزّل `mini-browser-apk` من قسم Artifacts.
